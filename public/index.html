    What we can see

    What our server sees, and what it never does. Everything after the # in a link stays in your browser. That's where the key lives.

    Protections

    • AES-256-GCM encryptionRuns in your browser's built-in Web Crypto. No crypto libraries. Always on
    • Passphrase stretchingPBKDF2-SHA256 with 600,000 iterations. When you set one
    • Padded sizesStored size shows only a rough range, never the exact length. Always on
    • Strict Content Security PolicyWith Trusted Types, so injected code can't run. Always on
    • No accounts, cookies or analyticsAnd no third-party scripts on any page. Always on
    • Key wiped from the address barThe page removes it as soon as the link opens. Always on
