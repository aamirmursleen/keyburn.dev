    Features

    Built for handing over logins, keys and files.

    • Tx

      Text and files

      Paste text, attach a file, or send both in one secret.

      64 KB text · 25 MB file

    • Ex

      Expiry

      When the timer runs out it's deleted, whether it was opened or not.

      15 minutes to 7 days

    • Vw

      View limit

      Choose how many times it can be opened. The last view deletes it.

      1, 2, 3, 5 or 10 views

    • Pp

      Passphrase

      An optional second lock that never leaves your browser. Too many wrong guesses destroy the secret.

      5 tries, then it's gone

    • Rc

      Private receipt

      A link only you get. See when it was opened and from which country, or destroy it early.

      Destroy any time

    • Rq

      Request a secret

      Send a request link. Your client answers once, and only you can open the reply.

      Request a secret

    Security

    What our server sees, and what it never does.

    Everything after the # in a link stays in your browser. That's where the key lives.

    Protections

    • AES-256-GCM encryptionRuns in your browser's built-in Web Crypto. No crypto libraries. Always on
    • Passphrase stretchingPBKDF2-SHA256 with 600,000 iterations. When you set one
    • Padded sizesStored size shows only a rough range, never the exact length. Always on
    • Strict Content Security PolicyWith Trusted Types, so injected code can't run. Always on
    • No accounts, cookies or analyticsAnd no third-party scripts on any page. Always on
    • Key wiped from the address barThe page removes it as soon as the link opens. Always on
