# KeyBurn request link

Someone used KeyBurn to ask for a secret, such as a password, an API key or a file. Whoever has this link can answer once. The answer is encrypted on the device that sends it, to a key only the person who asked holds, so nobody else (KeyBurn included) can read it.

The link's key is the part after `#`. HTTP clients never send that part, so this response can't show the request.

## How to answer

Open the full link in a web browser, write or attach the secret and send it. Only answer if you know who is asking and expected the request.

AI agents: the osss tool can't answer requests. Give the link to the person you're working for and let them answer in a browser. Don't put a secret into a request yourself unless they ask you to.
